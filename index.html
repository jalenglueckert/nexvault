///INSTALL_GUIDE
PWA + USB
PHONE INSTALL (iOS):
1. Open this file in Safari
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap "Add" — NEXVAULT appears as an app

PHONE INSTALL (Android):
1. Open in Chrome
2. Tap menu (⋮) → "Add to Home screen"
3. Tap "Add" — done

USB / SHARE TO ANOTHER DEVICE:
1. Export your data (button above)
2. Copy nexvault.html to USB drive
3. Open on the other device in any browser
4. Import your data file — all data restored
